# 远程分支拉取到本地


## 一、还没克隆仓库（第一次拉）
```bash
git clone 仓库地址
```
克隆后会自动进入项目目录，并默认切到 `main` / `master` 分支。

---

## 二、已经有本地仓库，要拉远程分支并切换
### 1. 先同步远程最新分支信息
```bash
git fetch origin
```

### 2. 查看有哪些远程分支
```bash
git branch -r
```

### 3. 拉取远程分支并创建本地分支（关键命令）
```bash
git checkout -b 本地分支名 origin/远程分支名
```

示例：
```bash
git checkout -b dev origin/dev
```

> 新版 Git 也可以用：
```bash
git switch 远程分支名
```
会自动创建同名本地分支并关联。

---

## 三、如果只是想拉最新代码并切换已有本地分支
```bash
git pull origin 分支名
git checkout 分支名
```

---

### 最简记忆版
- 第一次：`git clone`
- 已有仓库：`git fetch` → `git checkout -b 本地分支 origin/远程分支`
