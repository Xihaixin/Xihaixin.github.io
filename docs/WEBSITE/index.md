# Material 介绍

Material for MkDocs 是 MkDocs的一个主题配置，同时也是一个功能齐全的静态网站生成工具。
有哪些知名项目或网站也在使用 Material 来生成静态站点 ？

Material for MkDocs 使用广泛，下面是一些大公司和知名开源项目的使用例子：

## Python 领域

| 项目 | 域名 | 类别 |
| :--- | :--- | :--- |
| **FastAPI** | [fastapi.tiangolo.com](https://fastapi.tiangolo.com) | Web 框架 |
| **Pydantic** | [docs.pydantic.dev](https://docs.pydantic.dev) | 数据验证 |
| **Ruff** | [docs.astral.sh/ruff](https://docs.astral.sh/ruff) | Python 代码检查工具 |
| **UV** | [docs.astral.sh/uv](https://docs.astral.sh/uv) | Python 包管理器 |
| **Polars** | [pola-rs.github.io/polars](https://pola-rs.github.io/polars) | DataFrame 库 |
| **LlamaIndex** | [docs.llamaindex.ai](https://docs.llamaindex.ai) | LLM 数据框架 |
| **Ultralytics** | [docs.ultralytics.com](https://docs.ultralytics.com) | YOLO / ML |

## 总结

Material for MkDocs 早已不仅限于 Python 生态的工具。它服务于 Rust 项目（Polars、UV、Ruff）、Go 项目（GoReleaser）、JavaScript 项目（Electron）、C/C++ 项目（WebKit、OpenSSL），甚至是硬件/IoT 文档（Arduino、Pi-Hole）。这种跨语言的采用情况是该项目价值主张最有力的证明：无论你使用什么技术栈，它都能让文档编写变得毫无摩擦。
