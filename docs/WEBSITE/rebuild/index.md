# 本站改造记录

这个博客用 MkDocs Material 搭起来之后，我又零零碎碎改了几轮。改的时候觉得都挺顺，过一阵子回头看，却常常忘了当初为什么这么写。所以干脆把过程记下来。

一共动了四块：

| | 改了什么 |
| :--- | :--- |
| [重做首页](homepage.md) | 从一段自我介绍，变成一个像样的门户 |
| [统一全站风格](theme.md) | 把默认配色换成自己喜欢的 |
| [文章元数据](metadata.md) | 给每篇文章补上作者、日期和摘要 |
| [访问统计](analytics.md) | 接上 Google Analytics，看看有没有人来 |

改动主要落在两个文件：`mkdocs.yml` 和 `docs/stylesheets/extra.css`，另外加了两个构建钩子。原则只有一条——能用现成配置解决的，就别自己造轮子。
